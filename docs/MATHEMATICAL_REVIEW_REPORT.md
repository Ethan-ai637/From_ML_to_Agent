# v2.2 Mathematical Review Report

This release audited assumptions, proof steps, notation, figure/claim correspondence, problem solutions, and the boundary between conference-paper evidence and textbook-level fact.

## Audit summary
- Core proof files reviewed: 40/40.
- Student Problem Sets vs instructor solutions: 11 sets / 66 problems.
- Capstones reviewed: 8/8.
- Frontier Labs re-executed: 22/22, plus 6 basic labs.
- Claim taxonomy: Definition / Theorem-Proposition / Derivation / Empirical Finding / Interpretation / Open Question.

## Material corrections
The review tightened risk-decomposition language, Gibbs support handling, importance-sampling terminology, Xavier/He scope, LayerNorm scale invariance, self-attention permutation-equivariance scope, RoPE/length-generalization boundaries, Best-of-N assumptions, coverage claims, KL-policy support language, RLVR support terminology, POMDP belief sufficiency, Bellman conditions, A* assumptions, recourse claims, instructor SVD examples, and the Ch21 paired experimental design.

## Evidence-boundary policy
Frontier cards use attribution language for empirical results. A conference award identifies relevance, not universal truth. Toy labs establish sufficiency of a mechanism in a controlled system; they do not establish that the same causal mechanism is used by a production LLM.
